## Apply and verify

- On each repository homepage, edit its About description and topics; preserve accurate existing topics and avoid unrelated keyword stuffing.
- Set the website link to an appropriate public project page or the portfolio site where useful.
- On the profile, customize pinned repositories using the list above.
- Confirm links, visible descriptions and topics after saving.
- Verify each project's latest CI results and evidence limitations before describing it as tested or deployed.
- Use the [recruiter guide](RECRUITER_START_HERE.md) and [full profile](README.md) as the canonical career navigation.

## Maintenance

Review this list when a new flagship project is published or the target role changes. Keep project descriptions specific, concise and accurate. Do not use artificial stars, automated engagement or misleading proficiency and deployment claims.
